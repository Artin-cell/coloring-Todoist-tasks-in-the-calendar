# 🌈 Todoist → Google Calendar: синхронизация цветов

Автоматически окрашивает события Google Calendar на основе разделов задач в Todoist. Проект состоит из двух файлов Google Apps Script.

## 📁 Структура проекта

### `main.gs` — Основной скрипт
- Настройки подключения к Todoist и Google Calendar
- Основная логика синхронизации цветов
- Веб-интерфейс для ручного запуска

### `getTodoistSections.gs` — Вспомогательный скрипт
- Получает ID разделов Todoist
- Выводит список разделов в консоль

## 🚀 Быстрый старт

### 1. Токен Todoist API
1. Перейдите в [Настройки Todoist](https://todoist.com/app/settings/integrations)
2. Откройте раздел **Разработчик**
3. Скопируйте **API-токен**
4. Вставьте в `main.gs`:
```javascript
const CONFIG = {
  todoist: {
    apiToken: 'YOUR_TOKEN_HERE' // ← Вставьте сюда
  }
}
```

### 2. Получение ID календаря
1. Откройте [Google Calendar](https://calendar.google.com)
2. Найдите нужный календарь на левой панели
3. Нажмите ⋮ → **Настройки и общий доступ**
4. Скопируйте **Идентификатор календаря**
5. Вставьте в `main.gs`:
```javascript
calendar: {
  id: 'СКОПИРОВАННЫЙ_ID@group.calendar.google.com'
}
```

### 3. Получение ID разделов Todoist
1. В редакторе Apps Script выберите функцию `printTodoistSections`
2. Нажмите **Выполнить** (▶️)
3. Откройте **Журнал выполнения** (🐞 → Журналы)
4. Скопируйте ID разделов вида: `"Работа" -> ID: 123456789`

### 4. Настройка цветов
В `main.gs` замените примеры на реальные ID ваших разделов:
```javascript
sectionColors: {
  '123456789': '7',  // Работа → Павлин
  '987654321': '1',  // Личное → Лавандовый
  '456789123': '5'   // Проекты → Банан
}
```

## ⚙️ Настройка автоматизации

### Веб-приложение
1. В редакторе Apps Script: **Развернуть** → **Новое развёртывание**
2. Тип: **Веб-приложение**
3. Доступ: **От моего имени**, **Доступ: Все**
4. Скопируйте URL для ручного запуска

### Триггер по времени
1. В редакторе Apps Script: ⏰ **Триггеры** → **Добавить триггер**
2. Настройки:
   - **Функция:** `updateEventColors`
   - **Развёртывание:** Head
   - **Событие:** По времени
   - **Тип:** Ежедневно / Ежечасно
   - **Время:** Выберите удобное

## 🔧 Функции

### `doGet()` — Веб-интерфейс
- Запуск синхронизации вручную через HTTP GET-запрос
- Возвращает JSON с результатом выполнения
- URL: `https://script.google.com/.../exec`

### `updateEventColors()` — Основная синхронизация
- Получает задачи из Todoist **по разделам** (не все сразу)
- Получает события календаря за диапазон: 5 дней назад → 30 дней вперёд
- Строит карту: название задачи → ID цвета
- Обновляет цвет события только если он отличается от нужного
- Поддерживает пагинацию — корректно работает с разделами, в которых больше 50 задач

### `getTasksBySection(sectionId)` — Получение задач
- Запрашивает все задачи указанного раздела
- Обрабатывает пагинацию Todoist API через `nextCursor`

### `findColorForEvent(eventTitle, titleColorMap)` — Поиск совпадений
- Сначала ищет точное совпадение названия события и задачи
- Если не найдено — ищет частичное совпадение (одно содержит другое)

### `printTodoistSections()` — Помощник настройки
- Выводит все разделы Todoist с их ID в консоль
- Используйте для получения ID для `sectionColors`

## 📊 Как это работает

1. **Получение событий** из Google Calendar (5 дней назад → 30 дней вперёд)

2. **Получение задач по разделам** — для каждого ID раздела из `sectionColors` скрипт запрашивает только задачи этого раздела через `/tasks?section_id=...`

3. **Построение карты** названий задач → ID цветов

4. **Сопоставление и окраска** — для каждого события находит совпадающую задачу по названию (точное или частичное) и применяет соответствующий цвет

5. **Пропуск неизменённых** — если событие уже имеет правильный цвет, оно не обновляется

## 🐛 Отладка и логи

### Просмотр логов
1. В редакторе Apps Script
2. **Журнал выполнения** (🐞 → Журналы)
3. В логах отображается:
   - Количество найденных событий
   - Задачи, полученные по каждому разделу
   - Счётчики обновлённых / пропущенных / не найденных

### Частые ошибки
```
❌ Календарь не найден
→ Проверьте CONFIG.calendar.id в main.gs

❌ Ошибка Todoist API
→ Проверьте CONFIG.todoist.apiToken

? Совпадение не найдено для: "Название события"
→ Убедитесь, что в одном из настроенных разделов есть задача с таким же названием
```
